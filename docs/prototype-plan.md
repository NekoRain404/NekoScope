# NekoScope H5 交互原型

用户已确认名称与产品方向，并授权在 Development/NekoScope 创建模拟数据 H5 原型。

## 范围与设计

六个页面：概览、硬件详情、传感器、压力测试、基准测试、报告。深色侧栏配浅色工作区，可切换深色主题。紫色主色，辅以青绿状态色；桌面布局优先，同时适配窄屏。

所有数据均模拟，不读取系统、不执行外部工具、不产生真实压力负载。全局明确显示演示状态。报告下载必须注明模拟数据。复用 Chart.js 和 Lucide，原生 HTML/CSS/JavaScript，以 Vite 启动和构建。

## 实施步骤

- [x] 实现跨页面保留运行状态的压力测试和基准测试模拟，支持停止、完成和记录。

## 验收

1. 六个导航入口可用，搜索可定位硬件或传感器，刷新保留路由。
2. 传感器筛选、收藏、暂停显示、统计重置可用。
3. 压力测试参数影响模拟负载；启动、停止、完成、切换页面均无孤立状态。
4. 基准测试完成后生成可对比的模拟结果；停止不伪造完成结果。
5. 报告按所选内容生成，导出为可打开的 HTML / 合法 JSON，默认脱敏。
6. 深浅主题、键盘操作、窄屏布局可用；无浏览器异常；npm run build 成功。
